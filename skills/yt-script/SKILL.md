# yt-script

本檔是改編，不是 Jake Schincariol 的官方專案。上游與授權見倉庫根目錄。

一個點子，寫成一支 3 分鐘以內、有人願意看完的短影音。預設 20 到 45 秒。

這個資料夾裡的 `hookscore.py` 要真的跑。不要用眼睛估開頭。

```bash
python3 hookscore.py hooks.txt
python3 hookscore.py --hook "為什麼你會在第三秒滑走？"
```

## 動筆之前

1. 讀這份專案的 `templates/voice.md`，或使用者已經填好的那份語氣檔。裡面是對誰說話、實際怎麼講、不用的詞、不宣稱的事。沒有這份檔，先問使用者要三支他自己的公開影片，或三段他自己的口播，再整理成語氣檔。語氣不對的稿，他得親口念出來，比沒有稿更糟。
2. 不發明數字、成果或來源。數字會讓句子更強、但你沒有，就問，或寫成沒有數字的句子。

## 形狀

前 1 到 3 秒是整支片的工作。它要做三件事，否則人會滑走：對上標題剛承諾的事、打開一個還沒合上的問題、讓人相信後面真的有東西。

1. **開頭。** 對照 [21 種公式](hooks.json) 寫五句。每句都要能在大約 1 到 3 秒念完。丟進 `hookscore.py`，留下分數較高的兩句，兩句都給使用者看。不要只交一句。
2. **轉折（大約第 3 到第 8 秒）。** 用一句話說這支片要做什麼，然後就開始做。不要頻道介紹，不要「在開始之前」，不要叫人追蹤。那是前幾秒流失最常見的原因。
3. **正文。** 一拍只講一個點。每一拍都寫畫面上有什麼，不要只寫嘴上說什麼。只有臉、沒有東西可看，這支片就像沒畫面的錄音。
4. **交付。** 把開頭承諾的東西交出來，而且說你正在交：「封面那一行就是這句，打在畫面上。」
5. **結尾。** 只留一個要求。追蹤、留言、分享，三選一。

口播長度用粗估，不要寫滿：中文大約 4.5 字／秒，英文大約 2.5 個單字／秒。30 秒大約 130 個中文字，3 分鐘大約 800 個中文字，還要留氣口和畫面。超過 3 分鐘就改長片，章節才用 `/yt-chapters`。

## 四個出口

同一支片交四種包裝，字不要互相複製：

- **Shorts：** 標題，另外跑 `/yt-package`。
- **Reels：** 封面第一幀上的字，8 個中文字以內。
- **TikTok：** 前兩秒畫面上的字，和口播第一句不同詞。
- **Threads：** 第一行要能獨立看懂。不寫私人帳號，不把平台內部規則貼出去。

## 交回來的東西

- 兩句較高的開頭，附上評分面板
- 一拍一拍的腳本，每一拍都有 `[畫面上：...]`
- 以 4.5 字／秒粗估的秒數，並註明這不是完播預測
- 一行說明勝出的那句用了哪一種公式，以及為什麼適合這個點子

## 市場

預設 `--market tw`（zh-TW，繁體）。也可以用 `hk`（zh-HK）、`mo`（zh-MO）、`sg`（zh-SG）、`cn`（zh-CN）。

澳門是獨立市場，不是香港的別名。工具看到跨市場用詞、字形或引號時只標示，不改寫原句，也不做機械的繁簡轉換。各市場的平台清單是可編輯預設，不是使用率。沒有合規或法律保證。發布前請自己查看該平台目前的規則。

## 最後一關

這裡不發佈。技能負責寫，使用者自己上傳。每次輸出的最後一行都是：「要發出，還是再改？」
