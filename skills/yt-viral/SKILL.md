# yt-viral

本檔是改編，不是 Jake Schincariol 的官方專案。上游與授權見倉庫根目錄。

指令名稱沿用上游的 yt-viral。它不做的事比名稱更重要：它不預測一支片會不會被大量觀看，也不替你去收集清單。

原始觀看數比的是帳號大小，不是點子。這個工具比的是**相對該帳號自己中位數的倍數**。

```bash
python3 swipe.py collected.json --min 2.0
```

## 輸入從哪裡來

每個帳號至少**四支**，否則中位數沒有意義，工具會跳過並寫出來。

```json
[{"channel":"示範頻道","title":"...","views":12000,"url":"","duration":38}]
```

清單由使用者自己準備，存成本機 JSON。這個工具只讀那個檔。它不上網、不登入、不讀憑證，也不要使用者交出帳號。不要為了填這份檔去抓私人後台。

公開頁面上看得到的標題和觀看，若使用者已經自己抄進 JSON，可以分析。技能本身不發起連線。

## 怎麼讀結果

倍數是信號。公式那一行只是標題字面，對上 [21 種公式](../yt-script/hooks.json)，不是這支片有觀看的原因。交給使用者時要說這句。

交回來的東西：倍數最高的五支、各自的字面公式、它們共用的一個結構。然後更難的一行：這週使用者用自己的語氣、用已經有的素材，實際做得出哪一個。

時長超過 180 秒的，標成可選的長片參考，不要把它當成短影音範本。短影音看的是前 1 到 3 秒能不能獨立成立。

## 市場

預設 `--market tw`（zh-TW，繁體）。也可以用 `hk`（zh-HK）、`mo`（zh-MO）、`sg`（zh-SG）、`cn`（zh-CN）。

澳門是獨立市場，不是香港的別名。工具看到跨市場用詞、字形或引號時只標示，不改寫原句，也不做機械的繁簡轉換。各市場的平台清單是可編輯預設，不是使用率。沒有合規或法律保證。發布前請自己查看該平台目前的規則。

## 最後一關

這裡不發佈。技能負責寫，使用者自己上傳。每次輸出的最後一行都是：「要發出，還是再改？」
