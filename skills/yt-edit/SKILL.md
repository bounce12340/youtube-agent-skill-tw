# yt-edit

本檔是改編，不是 Jake Schincariol 的官方專案。上游與授權見倉庫根目錄。

有時間碼的字幕，換成一份剪輯清單。工具只印清單。使用者自己在剪輯軟體裡下刀。

```bash
python3 deadair.py transcript.srt
python3 deadair.py transcript.vtt --floor 0.30 --json
python3 deadair.py whisper.json
```

還沒有字幕就先要一份。不要猜時間碼。Whisper 一類的本機轉寫可以，重點是產出 srt、vtt 或帶 `segments` 的 JSON。這個技能不上網，也不讀帳號。

## 它找什麼

- **DEAD，空檔。** 長過門檻的缺口，從中間剪，兩邊各留半個門檻當氣口。貼著語音剪，收緊之後會像喘。預設門檻 0.45 秒。短影音若要更緊，再用 `--floor 0.30`，不要先把預設砍到連換氣都不留。
- **FILLER，口頭禪。** 整格都是「嗯」「那個」「就是」「然後」「對」「好」，或 um、you know、basically 這類。句子裡面夾一個「就是」不會整句刪掉，因為那常常是內容。
- **REPEAT，重拍。** 同一句又起了一次。對的是上一格真正的話，不是中間隔著的「嗯」。中文比對前 8 個字，英文比對前 5 個單字。

## 雙語字幕

英文一行、繁中一行，或同一格裡兩種字，只要有一行是內容，就整格保留。兩行都是口頭禪才標 FILLER。不要為了對齊把有內容的那一行剪掉。

## 它不做的事

它不碰影片檔，也沒有意見要不要補畫面。報告底部若說少了四成，那是口播少了四成。片中如果有一段沒有說話的示範，這個數字會偏短。下刀前對一下畫面。

口頭禪清單不是全集。新的語助詞會漏。單獨一格「好」或「對」若其實是在回答問題，清單仍會標出來，剪的人要略過。

## 最後一關

這裡不發佈。技能負責寫，使用者自己上傳。每次輸出的最後一行都是：「要發出，還是再改？」
