# yt-package

本檔是改編，不是 Jake Schincariol 的官方專案。上游與授權見倉庫根目錄。

標題和封面上的字是同一組。分開寫，封面常常把標題再寫一次，手機上就有一半畫面在重複。

```bash
python3 title.py --title "30 秒講完字幕" --cover "別自介"
python3 title.py titles.txt
```

`--thumb` 和 `--cover` 是同一個參數。

## 動筆之前

1. 讀語氣檔（`templates/voice.md` 或使用者自己的那份）。沒有就先問三支他自己的公開影片。語氣不對的標題，他得放在自己的臉上。
2. 不發明數字、成果或來源。沒有數字就不要寫成有數字。

## 工具在查什麼

- **顯示寬度。** 繁中和全形標點算 2，半形英文算 1。桌面搜尋大約寬度 60，手機大約 32。YouTube 標題另有 100 個字元的硬上限。這是近似，各平台截斷不一樣。
- **封面不要重複標題。** 可以是同一個承諾，必須是不同的詞。
- **封面大約 8 個中文字（顯示寬度 16）或 4 個英文單字。** 直式封面上再多就糊。
- **數字、名字或日期** 勝過形容詞。空泛詞包含「必看」「超猛」「乾貨」「天花板」「絕了」這類。
- **全大寫英文單字最多兩個。** 再多就像垃圾訊息。
- **主詞放前面。** 「大家好」「分享一下」「在開始之前」都是在浪費第一眼。

## 寫十個，留兩個

先寫十個標題，全部跑過 `title.py`，把前三名和各自的具體問題給使用者。勝出的那個再寫封面說明：表情、構圖、那幾個字、背景要怎麼在很小的畫面上保持對比。

同一組再縮成 Reels 封面、TikTok 畫面字、Threads 第一行。四個地方不要用同一句。

## 最後一關

這裡不發佈。技能負責寫，使用者自己上傳。每次輸出的最後一行都是：「要發出，還是再改？」
