# yt-seo

本檔是改編，不是 Jake Schincariol 的官方專案。上游與授權見倉庫根目錄。

搜尋比包裝小，比多數人以為的更有用在能長期被找到的片上。若這支片主要是給已追蹤的人看，就直說，把力氣放回 `/yt-package`。

## 動筆之前

1. 讀語氣檔。沒有就先問三支公開影片。
2. 不發明數字、成果或來源。

## 描述

- **前兩行才有人讀。** 它們出現在「更多」上面，也是搜尋摘要。用觀眾會打的詞，講這支片給了什麼。
- 若有連結或檔案，放在這兩行下面，讓它還在折疊之前。
- 長片才接章節，交給 `/yt-chapters`。3 分鐘以內不要硬湊章節。
- 然後才是長版：涵蓋什麼、給誰、假設對方已經會什麼。

## 標籤，老實說

YouTube 的標籤是弱信號，平台自己也這樣說。只用來消歧義：常見拼法、工具名稱、觀眾真的會打的縮寫。十五個夠了。把無關的詞塞滿不是策略，也違反平台條款。

IG、TikTok、Threads 的主題標籤同樣不是主策略。三到五個精準的，勝過一整排。不要為了湊數把這支片沒講的題目加進去。

## 搜尋句測試

交出去之前，寫出這支片應該贏過的三句搜尋，用台灣觀眾會打的詞。檢查標題和描述前兩行有沒有這些詞。沒有的話，問題在標題，不在描述。

Threads 配套的第一行要能獨立看懂，不依賴影片畫面，也不寫私人帳號。

## 市場

預設 `--market tw`（zh-TW，繁體）。也可以用 `hk`（zh-HK）、`mo`（zh-MO）、`sg`（zh-SG）、`cn`（zh-CN）。

澳門是獨立市場，不是香港的別名。工具看到跨市場用詞、字形或引號時只標示，不改寫原句，也不做機械的繁簡轉換。各市場的平台清單是可編輯預設，不是使用率。沒有合規或法律保證。發布前請自己查看該平台目前的規則。
