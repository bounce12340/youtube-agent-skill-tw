# yt-chapters

本檔是改編，不是 Jake Schincariol 的官方專案。上游與授權見倉庫根目錄。

章節是長片的可選項。Shorts、Reels、TikTok 這種 3 分鐘以內的片，不要為了有章節而加章節。

```bash
python3 chapters.py transcript.srt --target 8
```

## 規則不是建議

任一條不合，整段貼進描述也不會變成章節：

- 第一條必須是 **0:00**。
- 至少 **三條**。
- 每一條至少 **10 秒**。

工具會檢查這三條。不合就明講，不要讓使用者把無效清單貼出去。總長不到 30 秒時，工具會拒絕，因為數學上排不出三條。

## 每一行都要改寫

`chapters.py` 找的是邊界：你真正停下來的空檔，加上空檔前後用詞差多少。中文沒有空格，所以用常用字過濾後的二字組，不是斷詞器，也不是摘要模型。它印出的標題是草稿。

「封面標題手機截斷」這種是占位。改成那一段的承諾，用使用者的語氣，三到五個詞。

章節也是停留的診斷：一段若五個詞講不完，它就是兩段，或它是填充。

## 最後一關

這裡不發佈。技能負責寫，使用者自己上傳。每次輸出的最後一行都是：「要發出，還是再改？」
